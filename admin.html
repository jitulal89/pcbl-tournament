PCBL Rules

Unlimited roster

Add any number of players to each team.

Match types

Men's Singles, Women's Singles, Men's Doubles, Women's Doubles and Mixed Doubles.

Lineup validation

Singles require 1 player; doubles require 2. Gender combinations are checked for the selected match type.

Scoring

Best of 3 games, 21 points. At 20-all, continue until a 2-point lead, capped at 30.

Player rotation

The system warns when the same player is selected repeatedly in a fixture sequence; final PCBL rotation rules can be tightened once your exact event format is supplied.
